# 🤖 Healthcare ChatBot using Azure Bot Services

## 🩺 Overview

This project is a **Healthcare ChatBot** built using **Azure Bot Services** and **QnA Maker**, designed to answer common health-related queries instantly. It aims to assist users by providing quick, reliable information via a conversational interface.

👉 **Live ChatBot:** [Click here to interact](https://anamikatiwari2002.github.io/Healthcare_ChatBot/)

---

## 💡 Features

- **⚙️ Azure Bot Services Integration**  
  Built using Microsoft's cloud-based bot framework for scalability and easy deployment.

- **📚 QnA Maker**  
  Utilizes a pre-trained knowledge base to answer frequently asked medical questions.

- **🌐 Responsive Frontend**  
  Developed using **HTML**, **CSS**, and **JavaScript** to ensure a seamless experience across devices.

- **🚀 Live Deployment**  
  Hosted via **Azure Web Apps**, accessible through the provided public URL.
